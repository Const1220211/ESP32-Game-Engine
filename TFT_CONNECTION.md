# 📺 Подключение TFT дисплея ST7735S (Пины: VCC, GND, CS, RESET, A0, SDA, SCK, LED)

## 🔌 Прямое Подключение

| Вывод Дисплея | ESP32 Pin | Описание |
|---------------|-----------|----------|
| **VCC** | 3.3V | Питание (+3.3V) |
| **GND** | GND | Земля (минус) |
| **CS** | GPIO5 | Chip Select (выбор дисплея) |
| **RESET** | GPIO17 | Сброс дисплея |
| **A0** | GPIO16 | Data/Command (режим данные/команда) |
| **SDA** | GPIO23 | MOSI - данные в дисплей |
| **SCK** | GPIO18 | SPI Clock - синхронизация |
| **LED** | GPIO4 | Подсветка (светодиод) |

## 🎯 Схема Подключения

```
ESP32                          TFT 1.8" Дисплей
┌─────────────────┐           ┌─────────────────┐
│                 │           │                 │
│ GPIO5 (CS) ────────────────→ CS              │
│ GPIO17 (RST)───────────────→ RESET           │
│ GPIO16 (DC/A0)─────────────→ A0              │
│ GPIO23 (MOSI)──────────────→ SDA             │
│ GPIO18 (SCK)───────────────→ SCK             │
│ GPIO4 (BL)─────────────────→ LED             │
│ 3.3V ──────────────────────→ VCC             │
│ GND ───────────────────────→ GND             │
│                 │           │                 │
└─────────────────┘           └─────────────────┘
```

## 📋 Пошаговое Подключение

### Шаг 1: Припаяйте провода к дисплею
Если дисплей без штырьков, припаяйте следующие провода:
- **VCC** → Красный провод
- **GND** → Черный провод  
- **CS** → Оранжевый провод
- **RESET** → Желтый провод
- **A0** → Зеленый провод
- **SDA** → Синий провод
- **SCK** → Фиолетовый провод
- **LED** → Белый провод

### Шаг 2: Подключите к ESP32

**Питание:**
```
Дисплей VCC  → ESP32 3.3V
Дисплей GND  → ESP32 GND
```

**SPI (Данные):**
```
Дисплей SDA  → ESP32 GPIO23
Дисплей SCK  → ESP32 GPIO18
```

**Управление:**
```
Дисплей CS    → ESP32 GPIO5
Дисплей RESET → ESP32 GPIO17
Дисплей A0    → ESP32 GPIO16
```

**Подсветка:**
```
Дисплей LED   → ESP32 GPIO4 (или напрямую на 3.3V для всегда включённой)
```

## ⚠️ ВАЖНО: Конденсаторы

**Обязательно добавьте конденсаторы для стабилизации:**

```
3.3V ──[10μF]──┬──→ Дисплей VCC
               │
             GND
```

И между VCC и GND дисплея:
```
VCC ──[10μF]──┬──→ GND дисплея
              │
```

## 🔧 Проверка Подключения

| Что Проверить | Как |
|--------------|-----|
| **Питание** | Используйте мультиметр - должно быть ~3.3V между VCC и GND |
| **SPI провода** | GPIO18 и GPIO23 не должны быть замкнуты |
| **CS контакт** | GPIO5 должен быть отдельно |
| **Контакты припаяны** | Проверьте что нет холодных пропоев |

## 🎨 Настройка Кода

В файле `main.ino` уже установлены правильные пины:

```cpp
#define TFT_CS     5    // Chip Select
#define TFT_RST    17   // Reset
#define TFT_DC     16   // Data/Command (A0)
#define TFT_MOSI   23   // SDA (данные)
#define TFT_SCK    18   // SCK (синхро)
#define TFT_BL     4    // LED (подсветка)
```

**Если у вас другие пины, измените эти строки!**

## 📺 Проверка в Arduino IDE

1. Подключите ESP32 через USB
2. В Arduino IDE откройте **Tools → Serial Monitor**
3. Установите скорость на **115200**
4. Загрузите код
5. В Serial Monitor должно появиться:
   ```
   === ESP32 Game Engine Starting ===
   [DISPLAY] Initializing TFT 1.8" Display...
   [DISPLAY] Display initialized successfully
   ```

## ⚡ Если Дисплей не работает

### Чёрный экран
- ✅ Проверьте питание (3.3V между VCC и GND)
- ✅ Проверьте LED подсветка включена (GPIO4 высокий уровень)
- ✅ Проверьте RESET провод подключен

### Мусор на экране
- ✅ Проверьте SPI провода (GPIO18, GPIO23)
- ✅ Использование коротких проводов (< 30см)
- ✅ Конденсаторы на питании

### Дисплей не инициализируется
- ✅ Проверьте правильность пинов в коде
- ✅ Проверьте CS (GPIO5) отдельно подключен
- ✅ Проверьте DC/A0 (GPIO16) подключен

## 💡 Альтернативные Пины (Если занят GPIO)

Если какой-то пин занят, можно использовать другой:

```cpp
// Доступные пины для замены:
#define TFT_CS     33   // или любой другой GPIO
#define TFT_RST    32   // или любой другой GPIO  
#define TFT_DC     14   // или любой другой GPIO
#define TFT_BL     12   // или любой другой GPIO

// SPI пины НЕЛЬЗЯ менять! (18, 23, 19 - это аппаратный SPI)
```

**НО помните:** GPIO18, GPIO23, GPIO19 - это аппаратные пины SPI и менять их нельзя!
